# Subtitles

English SRT files generated from the official broadcaster videos.

Convention: `<show>/s<SS>e<EE>.en.srt`

- `mehmed/s01e01.en.srt` — Mehmed S1E1
- `orhan/s01e01.en.srt` — Kurulus Orhan S1E1
- `salahuddin/s01e01.en.srt` — Salahuddin S1E1

Generated by `tools/generate_subtitles.py` from the SAME official
YouTube video that Kodi plays. Generated once, reused forever.

Kodi auto-attaches the SRT when the file exists; video plays normally
when it does not.
